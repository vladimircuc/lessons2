In a markdown cell, explain in 2 to 3 sentences why adding those features did not help, and what it says about tennis.

Example answer

Adding surface and match format barely changed the accuracy, which means the ranking gap already captures almost all of the predictable signal. A player's ranking reflects how they perform across surfaces and formats, so those extra columns tell the model little it did not already know. This points to a genuine ceiling: most of a match is decided by who is stronger on paper, and the rest is upset randomness that no feature can capture.

Task B · the redundant features

In a markdown cell, explain that rank and points carry the same information (they agree ~100% on the favorite), why that makes feature importance look unstable, and what you would do about it.

Example answer

Ranking and ranking points agree on the favorite essentially 100% of the time, because a better ranking always comes with more points, so they are effectively the same feature. When two features are redundant, a tree splits credit between them arbitrarily, which is why the importance flips from one to the other depending on the dataset. To keep the model simple and the importances interpretable, it would be reasonable to keep just one of them.

Task C · limitations

In a markdown cell, write a short paragraph with at least two honest limitations of the study.

Example answer

This study uses only simple pre-match features and ignores richer signals like recent form, head-to-head history, and surface-specific strength, which could improve predictions. It also merges 25 seasons, over which the ATP points system changed, so ranking points are not perfectly comparable across eras. Finally, it predicts only a binary winner and cannot account for injuries, retirements, or match context, all of which cap how accurate any model can be.
