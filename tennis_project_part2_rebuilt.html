Reshape into a real prediction problem

Go to your ## 3. Build Features section. This is where the two deletions happen.

Delete two things first. (1) The four lines building rank_diff, points_diff, age_diff, height_diff from winner minus loser. (2) The small cell right after them that printed favorite_wins / known. You are rebuilding both, correctly, below and in the next tab.

Task A · balanced target

Randomly assign each winner to player A or B, and make a target that is 1 when A won.

Solution
rng = np.random.default_rng(42)
df["winner_is_A"] = rng.random(len(df)) < 0.5
df["target"] = df["winner_is_A"].astype(int)
df["target"].value_counts(normalize=True)

You should see

Both values near 0.50. The target is now a real coin-flip question the model must earn.

Task B · symmetric features

Rebuild the four difference features as player A minus player B.

Solution
def a_minus_b(winner_col, loser_col):
    a = np.where(df["winner_is_A"], df[winner_col], df[loser_col])
    b = np.where(df["winner_is_A"], df[loser_col], df[winner_col])
    return a - b

df["rank_diff"]   = a_minus_b("winner_rank", "loser_rank")
df["points_diff"] = a_minus_b("winner_rank_points", "loser_rank_points")
df["age_diff"]    = a_minus_b("winner_age", "loser_age")
df["height_diff"] = a_minus_b("winner_ht", "loser_ht")

# drop any rows still missing a feature value, so the models never see a gap
feature_cols = ["rank_diff", "points_diff", "age_diff", "height_diff"]
df = df.dropna(subset=feature_cols + ["target"])

df[["target"] + feature_cols].head()

You should see

A table with the target and four features. rank_diff is now positive or negative roughly equally. The dropna line matters: scikit-learn errors on missing values, so we remove any leftover gaps here.

Add a markdown note: "Players relabeled A and B with a random coin flip so the target is balanced. Features are A minus B, from pre-match columns only (no aces, minutes, or score) to avoid leakage."

## Train / Test Split

Task A · time-based split

Train on the earlier 80% of the season, test on the later 20%.

Solution
df_sorted = df.sort_values("tourney_date")
cut = int(len(df_sorted) * 0.8)

You should see

Two numbers that add up to your match count, roughly 80/20. The test set is the later part of the season.

Task B · fill in the baseline (Section 5)

Under your ## 5. Baseline Model header, predict A wins when A is ranked better, and measure it on the test set.

Solution
from sklearn.metrics import accuracy_score

baseline_pred = (test["rank_diff"] < 0).astype(int)

Train two models (Section 6)

Fill in your ## 6. Train a Model section. First set up X and y, then train a logistic regression and a decision tree.

Task A · set up X and y

Split the features (X) and the target (y) for train and test.

Solution
feature_cols = ["rank_diff", "points_diff", "age_diff", "height_diff"]
X_train, y_train = train[feature_cols], train["target"]
X_test,  y_test  = test[feature_cols],  test["target"]

You should see

No output, this just names the four pieces. X_train/y_train are what the model learns from; X_test/y_test are the unseen matches we judge it on.

Task B · logistic regression

Create, fit, predict, and score a logistic regression.

Solution
logreg = LogisticRegression(max_iter=1000)
logreg.fit(X_train, y_train)
logreg_pred = logreg.predict(X_test)

logreg_acc = accuracy_score(y_test, logreg_pred)
print("logistic regression:", round(logreg_acc, 3))

You should see

An accuracy around 0.65 to 0.68, right in the neighborhood of the baseline.

Task C · decision tree

Do the same with a decision tree (cap the depth so it does not overfit).

Solution
tree = DecisionTreeClassifier(max_depth=4, random_state=42)
tree.fit(X_train, y_train)
tree_pred = tree.predict(X_test)

tree_acc = accuracy_score(y_test, tree_pred)
print("decision tree:", round(tree_acc, 3))

You should see

Another accuracy in the same 0.65 to 0.68 range. Two real models, trained and scored.
