Remember the rule: every feature reads its value before updating with the match result. Read first, update after. No exceptions.

Feature 1: experience (learn the loop)

Warm up with the simplest feature so the pattern is solid before Elo.

Your task

Walk the matches in order. For each one, record how many matches each player has played so far (before this match), then add one to each. Convert to an A-vs-B exp_diff column.

Solution
matches_played = defaultdict(int)
exp_w = np.zeros(len(df)); exp_l = np.zeros(len(df))

for i, row in enumerate(df.itertuples(index=False)):
    w, l = row.winner_id, row.loser_id
    exp_w[i] = matches_played[w]     # READ before
    exp_l[i] = matches_played[l]
    matches_played[w] += 1           # UPDATE after
    matches_played[l] += 1

df["exp_diff"] = np.where(is_A, exp_w - exp_l, exp_l - exp_w)

You should see

No output, this creates the exp_diff column. Quick check: df["exp_diff"].describe() should show a mix of positive and negative values centered near zero.

Quick check

Fit a logistic regression on exp_diff alone and print its accuracy.

Solution
train, test = df.iloc[:cut], df.iloc[cut:]
m = LogisticRegression(max_iter=1000).fit(train[["exp_diff"]], train["target"])
print("experience only:", round(accuracy_score(test["target"], m.predict(test[["exp_diff"]])), 3))

You should see

About 0.57. Weak on its own, but it proved the loop works. Now the same pattern with real power.

Feature 2: Elo (dynamic K)

The main event. Same loop, with the Elo update and a per-player step size.

Task A · build Elo

Everyone starts at 1500. For each match: read both ratings, compute the expected score, update both by dynamic_k × (actual - expected), and track each player's match count to feed the dynamic K. Make an elo_diff column.

Solution
elo = defaultdict(lambda: 1500.0)
games = defaultdict(int)
elo_w = np.zeros(len(df)); elo_l = np.zeros(len(df))

def dynamic_k(n):
    return 250 / ((n + 5) ** 0.4)

for i, row in enumerate(df.itertuples(index=False)):
    w, l = row.winner_id, row.loser_id
    a, b = elo[w], elo[l]
    elo_w[i] = a; elo_l[i] = b                       # READ first
    expected_w = 1 / (1 + 10 ** ((b - a) / 400))
    elo[w] = a + dynamic_k(games[w]) * (1 - expected_w)
    elo[l] = b - dynamic_k(games[l]) * (1 - expected_w)
    games[w] += 1; games[l] += 1                     # UPDATE after

df["elo_diff"] = np.where(is_A, elo_w - elo_l, elo_l - elo_w)

You should see

No output, but it runs over all matches in about a second and creates elo_diff.

Task B · sanity check the ratings

Print the five highest final Elo ratings with player names. They should be stars, that is how you know the feature is real.

Solution
names = df.drop_duplicates("winner_id").set_index("winner_id")["winner_name"]
top = pd.Series(elo).sort_values(ascending=False).head(5)
for pid, rating in top.items():
    print(names.get(pid, pid), round(rating))

You should see

Djokovic, Sinner, Federer, Alcaraz, Medvedev at the top. If you see unknown names or nonsense, something in the loop is off, check the read-then-update order.

Measure the lift & write it up

Compare to the baseline and record the result for your report.

Task A · the comparison

Solution
