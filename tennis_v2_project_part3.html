Feature 5: head-to-head

The prior record between the two specific players. Key made of two players.

Task A · build it

Track h2h[(x, y)] = times x has beaten y. Read the prior edge before the match, then give the winner one more.

Solution
h2h = defaultdict(int)
h2h_w = np.zeros(len(df))
for i, row in enumerate(df.itertuples(index=False)):
    w, l = row.winner_id, row.loser_id
    h2h_w[i] = h2h[(w, l)] - h2h[(l, w)]     # READ prior edge (0 if never met)
    h2h[(w, l)] += 1                          # UPDATE
df["h2h_diff"] = np.where(is_A, h2h_w, -h2h_w)

You should see

No output; it creates h2h_diff. The never-met case is handled automatically: defaultdict(int) returns 0, so no prior history gives a neutral 0.

Feature 6: rest

Days since each player's last match, with a default for first matches.

Task A · build it

Remember each player's last match date; rest is today's date minus that. Default to 30 days for a first match so the code does not crash.

Solution
last_date = {}
rest_w = np.zeros(len(df)); rest_l = np.zeros(len(df))
for i, row in enumerate(df.itertuples(index=False)):
    w, l, d = row.winner_id, row.loser_id, row.tourney_date
    rest_w[i] = (d - last_date[w]).days if w in last_date else 30
    rest_l[i] = (d - last_date[l]).days if l in last_date else 30
    last_date[w] = d; last_date[l] = d
df["rest_diff"] = np.where(is_A, rest_w - rest_l, rest_l - rest_w)

You should see

No output; it creates rest_diff. Check the spread with int(rest_w.max()), it is huge (injury comebacks), which the next task investigates.

Task B · test the outliers (do not just cap them)

Cap rest at 60 days and compare to the raw version on top of Elo + surface. Does capping help?

Solution
rest_w_cap = np.minimum(rest_w, 60); rest_l_cap = np.minimum(rest_l, 60)
df["rest_cap_diff"] = np.where(is_A, rest_w_cap - rest_l_cap, rest_l_cap - rest_w_cap)

train, test = df.iloc[:cut], df.iloc[cut:]
def acc(cols):
    m = LogisticRegression(max_iter=1000).fit(train[cols], train["target"])
    return round(accuracy_score(test["target"], m.predict(test[cols])), 4)
base = ["elo_diff", "surface_elo_diff"]
print("raw:   ", acc(base + ["rest_diff"]))
print("capped:", acc(base + ["rest_cap_diff"]))

You should see

Capped (~0.6465) is lower than raw (~0.6479). The big rest values are real signal (rusty comebacks), so capping hurts. Keep the raw values, and note this in your report.

The habit to keep: never clean or cap data on instinct. Test whether the change helps first, because outliers sometimes carry the most signal.
