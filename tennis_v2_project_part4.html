Features 7 to 9: career serve rates

Running totals plus a small-sample guard.

Leakage check first: use each player's serve stats from past matches only. Read the running totals before the match, add this match's serve numbers after. Never use this match's own aces as a feature.

Task A · build the rates

Track running serve totals per player. Rates come from totals divided by totals, with a guard that falls back to the tour average below 200 service points.

Solution
serve = defaultdict(lambda: np.zeros(6))   # [ace, svpt, 1stWon, 1stIn, bpSaved, bpFaced]
ace_w=np.zeros(len(df)); ace_l=np.zeros(len(df))
fsw_w=np.zeros(len(df)); fsw_l=np.zeros(len(df))
bps_w=np.zeros(len(df)); bps_l=np.zeros(len(df))

def rates(t):
    if t[1] < 200:                       # small-sample guard -> tour averages
        return 0.076, 0.712, 0.604
    return t[0]/t[1], t[2]/max(t[3],1), t[4]/max(t[5],1)

for i, row in enumerate(df.itertuples(index=False)):
    w, l = row.winner_id, row.loser_id
    ace_w[i],fsw_w[i],bps_w[i] = rates(serve[w])   # READ before
    ace_l[i],fsw_l[i],bps_l[i] = rates(serve[l])
    wv=[row.w_ace,row.w_svpt,row.w_1stWon,row.w_1stIn,row.w_bpSaved,row.w_bpFaced]
    lv=[row.l_ace,row.l_svpt,row.l_1stWon,row.l_1stIn,row.l_bpSaved,row.l_bpFaced]
    if not any(pd.isna(wv)): serve[w]+=np.array(wv,float)   # UPDATE after
    if not any(pd.isna(lv)): serve[l]+=np.array(lv,float)

df["ace_diff"]=np.where(is_A, ace_w-ace_l, ace_l-ace_w)
df["fsw_diff"]=np.where(is_A, fsw_w-fsw_l, fsw_l-fsw_w)
df["bps_diff"]=np.where(is_A, bps_w-bps_l, bps_l-bps_w)
